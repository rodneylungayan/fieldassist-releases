# FieldAssist

**AI writing help inside any Windows text field.**

Write rough notes in any app (email, chat, a ticket, a form), press **Ctrl+Alt+Space**, and FieldAssist hands back the same ideas in a sensible order, with spelling and grammar fixed, still sounding like you. Apply it straight into the field, or copy it.

👉 **Download and learn more: [rodneylungayan.com/apps/fieldassist](https://www.rodneylungayan.com/apps/fieldassist)**

## Download

Get the latest version from the [Releases](https://github.com/rodneylungayan/fieldassist-releases/releases/latest) page:

- **`FieldAssist-Setup.exe`** (recommended): installs for your user only, with no admin rights needed, and **updates itself** from Settings → Updates.
- **`FieldAssist-<version>.exe`**: portable, a single file with nothing installed. It does not update itself.

Requires Windows 10 or 11, 64-bit.

Windows SmartScreen may warn you the first time, because the installer is not code signed yet. Choose **More info → Run anyway**.
